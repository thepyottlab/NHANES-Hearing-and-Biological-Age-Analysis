# NHANES Hearing and Biological Age Analysis

This repository contains scripts and data to reproduce our analysis characterizing the
population-level hearing trajectory and additional predictive value of biological age beyond
chronological age in the NHANES dataset. The analysis was performed using R 4.5.3 on MacOS.

## Install

1.  Open `NHANES Analysis.Rproj` in RStudio.
2.  Install renv with `install.packages("renv")`.
3.  Run `renv::restore()`.
4.  Select `scripts/00_NHANES_analysis.Rmd` and press the `knit` button.
